# Fotos für die Website

Foto mit genau dem angegebenen Dateinamen in diesen Ordner legen. Es erscheint
automatisch an seinem Platz und ersetzt den gestrichelten Platzhalter.

- Format: JPG, lange Seite etwa 1600–2000 px, möglichst unter 400 KB
- Seitenverhältnis wie angegeben (sonst wird automatisch zugeschnitten)
- Fotos mit Bewohnerinnen, Bewohnern oder Mitarbeitenden nur mit deren
  schriftlichem Einverständnis verwenden

| Datei | Motiv | Format |
| --- | --- | --- |
| `hero.jpg` | Außenansicht des Schlosses mit Giebel und Steinportal, bei Sonne | Hochformat 4:5 |
| `hero-park.jpg` | Bewohnerin und Pflegekraft auf einer Bank im Schlosspark | 1:1 |
| `pflege.jpg` | Pflegekraft im Gespräch mit einem Bewohner | Querformat 3:2 |
| `zimmer.jpg` | Helles Einzelzimmer mit eigenen Möbeln | Querformat 3:2 |
| `alltag.jpg` | Kaffeerunde, Singen oder Vorlesen | Querformat 3:2 |
| `galerie-hof.jpg` | Der Schlosshof | 1:1 |
| `galerie-park.jpg` | Der Schlosspark mit alten Bäumen | 1:1 |
| `galerie-kapelle.jpg` | Die Hauskapelle mit Rokoko-Stuck | 1:1 |
| `galerie-speisesaal.jpg` | Der Speisesaal | 1:1 |
| `galerie-portal.jpg` | Das Steinportal von 1624 im Detail | 1:1 |
| `team-leitung.jpg` | Porträt der Heimleitung / Familie Brandner | Hochformat 4:5 |
| `team-gruppe.jpg` | Gruppenfoto des Teams vor dem Schloss | Querformat 3:2 |
| `stimme-1.jpg` bis `stimme-3.jpg` | Porträts der zitierten Angehörigen | 1:1 |
| `anfahrt.jpg` | Eingang von der Schloßstraße aus | Querformat 3:2 |

Nach dem Einfügen in `index.html` den `alt`-Text am jeweiligen Bild prüfen, damit
er beschreibt, was wirklich zu sehen ist.
